# WARP to AmneziaWG Auto-Config Generator & Modifier

Портативный автоматический скрипт для генерации актуальных конфигураций Cloudflare WARP и их конвертации в продвинутый формат **AmneziaVpn-AmneziaWG** с интерактивным выбором параметров маскировки (обхода DPI), автоматической интеграцией Xbox-DNS и поддержкой раздельного туннелирования.

## 🚀 Возможности пака
- **Умное слияние (Smart Merge):** Автоматически вытягивает актуальный `Device ID` и `License Key` из официального клиента WARP, регистрирует свежую сессию WireGuard, но бережно переносит выбранные вами настройки маскировки пакетов (SIP-заголовки `I1/I2`, Hex-мусор, параметры `Jc/Jmin/Jmax`).
- **Интерактивное меню:** Скрипт сам сканирует папку с шаблонами обхода блокировок и выводит их списком в консоли. Вам достаточно просто ввести цифру нужного пресета.
- **Встроенный Xbox-DNS:** В генерируемые конфигурации автоматически вшиваются специализированные DNS-серверы. Это решает проблему конфликта локаций (например, когда WARP выдает IP США) и открывает доступ к капризным зарубежным сервисам (включая ChatGPT, Xbox Live, PSN) без бесконечных капч и ошибок авторизации.
- **Два понятных режима работы:**
  - **Полный VPN** — пускает абсолютно весь трафик компьютера через замаскированный WARP.
  - **Выборочный VPN** — пускает через VPN только заблокированные сайты из базы `ip-list.json`, а весь остальной интернет (игры, стримы, банки) работает напрямую на максимальной скорости провайдера.
- **Абсолютная портативность:** Скрипт полностью автономен, не зависит от путей, дисков или имени пользователя в Windows. Он сам скачивает нужные бинарники (`wgcf.exe`) и создаёт готовые к импорту файлы конфигураций прямо в корне своей папки.

## 📥 Где скачать клиент Amnezia?

Для работы сгенерированных конфигураций вам понадобится специальный клиент **AmneziaVpn-AmneziaWG** (обычный WireGuard не подойдет, так как он не поддерживает параметры маскировки). 

Скачайте и установите актуальную версию для вашей системы:
* **Официальный сайт:** [amnezia.org](https://amnezia.org/) *(Может быть заблокирован некоторыми провайдерами)*
* **Официальное зеркало сайта:** [storage.googleapis.com/amnezia/...](https://storage.googleapis.com/amnezia/amnezia.org)
* **Официальный GitHub (Зеркало):** [AmneziaVPN Releases](https://github.com/amnezia-vpn/amnezia-client/releases) *(Рекомендуется. Всегда доступно из РФ, скачивайте файлы `.exe` или `.msi` актуального релиза)*

## 📦 Инструкция по установке и запуску

1. Перейдите в раздел **Releases** (Выпуски) справа на странице репозитория и скачайте актуальный архив проекта `Bypass-Cloudflare-WARP-AmneziaVPN.zip`.
2. Распакуйте архив в любую удобную папку на компьютере.
3. Убедитесь, что в вашей системе установлен и хотя бы раз был запущен официальный клиент **Cloudflare WARP**.
4. В зависимости от ваших целей, запустите нужный файл обычным двойным кликом:
   - Для полной маскировки всего ПК запустите: 
     **`Запустить - полный VPN (весь трафик ПК).bat`**
   - Для обхода блокировок конкретных сайтов запустите: 
     **`Запустить - выборочный VPN (только для сайтов).bat`**
5. В открывшемся консольном окне **выберите номер шаблона маскировки** (введите цифру от 1 до количества доступных конфигов и нажмите *Enter*).
6. Скрипт автоматически выполнит сбор данных, применит настройки Xbox-DNS и создаст готовый файл конфигурации в корне папки:
   - `AmneziaWG_WARP.conf` (для полного режима)
   - `AmneziaWG_Split.conf` (для выборочного режима)
7. Импортируйте полученный файл в установленный клиент **AmneziaVpn-AmneziaWG** (или добавьте туннель в AmneziaVPN) и нажмите кнопку **«Подключить»**. Официальный клиент WARP после этого можно отключить или закрыть-Можно удалить.

## 🧩 Как устроена кастомизация маскировки (Для продвинутых)

В папке `utils` по умолчанию лежат два проверенных шаблона-донора:
* **`WARPv3_33.conf`** — конфигурация с имитацией **SIP-телефонии** (интернет-звонков). Идеально подходит для пробития строгих DPI-фильтров.
* **`WARPv2_28.conf`** — конфигурация с использованием **Hex-мусора** (запутывания структуры пакетов случайными байтами).

### 💡 Как добавить свой собственный конфиг или новую маскировку?

Вам больше не нужно переименовывать файлы под старые названия или лезть в код скрипта. Система полностью автоматизирована:
1. Возьмите любой рабочий конфигурационный файл AmneziaWG (найденный в чатах, каналах или настроенный вами вручную).
2. Придумайте ему любое понятное имя (например, `WARPv4_Custom_Bypass.conf`) и просто перетащите его в папку **`utils`**.
3. Запустите любой батник из корня пака.
4. Скрипт на лету обнаружит новый файл, сам добавит его в интерактивное меню в консоли под новым номером, а после вашего выбора автоматически перенесет из него параметры маскировки (`Jc`, `Jmin`, `I1`, `I2`) на ваши личные лицензионные ключи WARP, сохранив настройки Xbox-DNS.

## 📅 Как обновить список сайтов для выборочного режима?

Если вам нужно обновить список заблокированных ресурсов:
1. Зайдите на сайт генератора списков (например, [iplist.opencck.org](https://iplist.opencck.org/ru/)).
2. Скачайте актуальный файл в формате **JSON**.
3. Переименуйте скачанный файл в `ip-list.json` и положите его в папку `utils`, заменив старый.
4. Перезапустите файл выборочного VPN. Скрипт мгновенно пересоберет конфиг с новой базой сайтов.
